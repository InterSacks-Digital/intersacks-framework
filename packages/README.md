# Packages

The `packages` directory contains the core building blocks of the InterSacks Framework.

## Package Overview

### design-tokens
Global design variables such as colors, typography, spacing, shadows, and breakpoints.

### foundation
Reusable CSS utilities and foundational styles built on the design tokens.

### components
Reusable UI components such as buttons, navigation bars, cards, forms, and galleries.

### layouts
Common page layouts and structural building blocks.

### animations
Reusable animation utilities and interaction effects.

### themes
Visual themes and industry-specific styling.

### icons
Shared icon assets and icon utilities.

### utils
Helper utilities and shared functionality used throughout the framework.

Each package is designed to be modular, reusable, and independently maintainable.
