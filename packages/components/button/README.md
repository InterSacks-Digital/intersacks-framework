# Button Component

## Purpose

The Button component provides a consistent interactive element across all InterSacks Framework editions.

## Features

- Primary
- Secondary
- Dark
- Light
- Small
- Large
- Pill
- Disabled

## Dependencies

Requires:

- Design Tokens
- Foundation

## Usage

```html
<button class="btn btn-primary">

Shop Now

</button>
```

## Variants

- btn-primary
- btn-secondary
- btn-dark
- btn-light
- btn-sm
- btn-lg
- btn-pill

## Accessibility

- Keyboard accessible
- Semantic HTML
- High contrast support
