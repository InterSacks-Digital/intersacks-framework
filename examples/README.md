# Examples

This directory contains working example projects built with the InterSacks Framework.

## Purpose

Examples demonstrate how the framework can be used to build complete websites across different industries.

## Planned Examples

- Boutique
- Salon
- Restaurant
- Gym
- Portfolio
- Coffee Shop
- Real Estate

Each example serves as a reference implementation and showcases recommended architecture, styling, and component usage.

These projects are not production websites. They exist purely as learning resources and implementation references.
