# InterSacks Framework

A modular frontend framework developed by InterSacks Digital for building elegant, high-performance business websites.

## Editions

- Boutique
- Salon
- Restaurant
- Gym
- Portfolio

## Core Features

- Responsive layouts
- Component-based architecture
- Animation library
- Theme system
- Design tokens
- Vanilla JavaScript
- Modern CSS
